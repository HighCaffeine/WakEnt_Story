=> 시네머신은 2D에서도 사용은 가능한데, 3D보다는 제한적이고 SFX랑 Material은 2D에서는 사용이 제한됨.
    3D로 하기에는 무리, 2D겜이라 시네머신 사용을 간단하게만 할 수 있는게 아쉽다 생각함.
    서버는 데이터 저장을 메인 서버에 하거나 랭킹 시스템, SQL이랑 엮어서 쓸 수도 있을 듯
    CDN이나 LUA로 업데이트를 하게 될 거 같고 LUA도 해본 적이 없어서 해보고 싶음.
    DB는 해보면 좋은데 JSON으로 처리하는게 간단하다보니 고민됨. 아무튼 SQL 해보면 좋을 듯.
    최적화는 3D의 물리연산이 가장 신경써야할 부분이다보니 2D겜이라 UI상의 배치수나 setpass 조절뿐일 듯.

=> 방송 장비들의 업그레이드가 되어가는 방식으로 방송 스텟이 증가하는 방식으로 생각

이세돌, 고멤, 아카데미, 짭멤 면접으로 뽑는 방식 
=> 왁굳형이 왁 엔터를 운영하는 컨셉이고
    이세돌 고멤 아카데미 3가지 성장률을 표기해서 
    플레이어가 3가지 중 원하는 멤버를 골라서 투자할 수 있고, 투자 방향에 따라 여러가지 상황이 나오는 방식 
    => 이거는 좀 생각해 봐야할 듯 멤버들을 다 등장시키기에는 너무 많고, 3d모델링 얻기도 그렇고
        여기를 좀 생각해서 2D로 변경이 필요하면 변경.

=> 아카데미는 작업계라고 생각해야 할 듯, 이세돌과 우왁굳 위주로 하게될 거 같고 고멤 및 아카데미까지 사용하기에는 무리라고 판단됨



캐릭터마다 능력치가 존재함.
각자 캐릭터를 조합 -> 각 캐릭터들의 컨텐츠 제작 능력치가 존재하고 각 능력치들은 성장 가능
왁타버스 멤버들로는 제한이 있기 때문에 이파리, 팬치들이 능력을 대신해줌( 유니티 및 언리얼을 사용한 컨텐츠 시 프로그래밍과 이미지가 사용됨)
팬덤을 많이 쓸 수록 능력이 오르고, 아카데미 및 작업계 인원들을 조합하여 방향성을 결정하고 유저가 직접 결과물의 이름을 만드는걸로 하면 될 듯.



이세돌 및 우왁굳 방송
노래방송, 게임방송을 주로 하고
어떤 방송을 할 지 정하고, 해당 방송에서 진행할 컨텐츠를 유저가 직접 캐릭터(작업계)를 사용하여 제작함.
해당 방송이 특정 조건(정해진 시청자 수 돌파 / 좋아요 수)을 달성 시 후속 컨텐츠로 이어서 가능.
=> 방송 컨텐츠를 만들 때 사용될 스텟치들을 정해야 함
      작업계 -> 작곡, 엔진(엔진 제작), 맵 제작, 컨텐츠 기획, 애니메이터, 캐릭터 등 여러가지 분야에서 방송을 도와주고 있음
      해당하는 특기들이 컨텐츠 제작에 작용하여 결과물의 영향을 받게 끔 하고싶고
      어떤 컨텐츠를 만들 것인가로 메인이 되는 키워드를 정하고 부가적으로 들어가는 키워드로 조합을 짜는 방식 => 게임을 하는데 어떤 게임/방식으로 하는지 ex) 게임 + 시참/합방 ->  배그삼국지 이런식

해당 부분은 좀 생각해봐야 할 듯 하고, 다른 방안도 생각해보는게 좋을 듯.
